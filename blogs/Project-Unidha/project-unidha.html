PROJECT OVERVIEW

About This Project

Background

This project focuses on the implementation of Building Information Modeling (BIM) in the structural planning and analysis of the Universitas Dharma Andalas Tower Building. The BIM approach was adopted to improve coordination, visualization, and construction documentation efficiency.

Objective

To develop an integrated BIM model that supports structural planning, visualization, quantity extraction, and technical documentation.

BIM MODELING PROCESS

Structural Model Development

The BIM model was developed progressively, starting from project setup and structural components to a fully coordinated building model.

STEP 01

Grid & Level Setup

Establishing grids and levels as the foundation of the BIM model.

STEP 02

Column Modeling

Modeling structural columns based on design specifications.

STEP 03

Beam Modeling

Creating beam systems to support structural integrity.

STEP 04

Floor Slab Modeling

Developing floor slabs for each building level.

STEP 05

Stair Modeling

Modeling vertical circulation components within the building.

STEP 06

Final BIM Model

Integrated structural model ready for documentation.

STRUCTURAL MODELING

BIM Structural Model

The structural BIM model was developed to represent the main load-bearing elements of the building, enabling visualization, coordination, and documentation throughout the project.

Columns

Reinforced concrete columns modeled according to structural design requirements.

Beams

Beam systems integrated to distribute loads throughout the structure.

Floor Slabs

Multi-level slab modeling supporting the building floor system.

Core Structure

Structural core providing vertical stability and circulation support.
